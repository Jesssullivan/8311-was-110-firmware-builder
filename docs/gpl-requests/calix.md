## Why Calix

The Calix 100-05610 SFP+ XGS-PON ONT is built on the same MaxLinear
PRX300 family as the WAS-110. Public reporting indicates it ships
Linux 4.9.337 with an OpenWrt 22.03.0-rc2 MaxLinear toolchain.
Calix's kernel is a *closer* revision to ours than AVM's PRX321
sources (4.9.276), so corresponding source from Calix would be the
single highest-value GPL drop for this project.
